# 매출·수금 트래커

엑셀 인보이스 목록을 붙여넣으면 국가·거래처별 월/분기 매출, 목표 달성률, 수금 D-day를 정리해 주는 웹 페이지입니다.

## 여는 방법
- `index.html`을 더블클릭하면 브라우저(Chrome, Edge, Safari 등)에서 열립니다.
- 설치나 로그인은 필요 없습니다.
- 인터넷이 연결돼 있으면 Google 글꼴로 보이고, 연결이 없으면 기본 글꼴로 보입니다. 기능은 똑같이 동작합니다.

## 쓰는 방법
1. 소개 페이지에서 "예시 데이터로 둘러보기"를 누르면 예시 데이터가 든 대시보드가 열립니다.

### 한 건씩 직접 입력하기
- 대시보드 위쪽 또는 "전체 인보이스" 표의 "인보이스 추가" 버튼을 누릅니다.
- 인보이스일, 결제 예정일, 거래처, 국가, 통화, 금액을 넣고 "추가하기"를 누릅니다.
  - 결제 예정일은 "발행일 +30일 / +60일 / +90일" 버튼으로 바로 넣을 수 있습니다.
  - 거래처·국가는 이미 입력한 이름이 자동완성으로 나옵니다.
- 예시 데이터가 들어 있는 상태에서 처음 추가하면, 예시를 지우고 내 데이터로 시작할지 고를 수 있습니다.

### 이미 들어간 인보이스 고치기·지우기
- "전체 인보이스" 표의 각 줄에 있는 "수정" 버튼을 누르면 같은 입력 창이 기존 값이 채워진 채 열립니다.
- "삭제" 버튼은 한 번 누르면 "정말 삭제"로 바뀌고, 한 번 더 눌러야 지워집니다.
- 추가·수정·삭제 직후 화면 아래 알림의 "되돌리기"를 누르면 바로 전 상태로 돌아갑니다.

### 엑셀에서 한꺼번에 넣기
2. 엑셀에서 아래 순서의 열을 범위로 복사(Ctrl+C)합니다.
   `인보이스일 | 거래처 | 국가 | 통화 | 금액 | 결제 예정일 | 수금 여부(선택)`
3. 대시보드의 "엑셀 붙여넣기" 칸에 붙여넣고(Ctrl+V) "반영하기"를 누릅니다.
   - 제목 줄은 있어도 괜찮습니다.
   - 수금 여부 칸에 "완료"라고 적으면 수금된 건으로 처리합니다.
   - 날짜는 2026-10-02, 2026.10.02, 2026/10/02 형식을 읽습니다.
4. 환율 칸에 원화 환산용 환율을 입력하고, 목표 칸에 국가별 연간 목표(백만원)를 입력합니다.

`예시_인보이스.tsv`를 엑셀로 열어 전체 복사한 뒤 붙여넣으면 바로 연습해 볼 수 있습니다.

## 알아두실 점
- 데이터는 지금 쓰는 브라우저 안에만 저장되고 서버로 보내지 않습니다. 다른 컴퓨터나 다른 브라우저에서는 보이지 않습니다.
- 브라우저의 사이트 데이터를 지우면 입력한 데이터도 지워집니다.
- 환율은 실시간이 아니라 직접 입력한 값으로 계산합니다. 처음 들어 있는 환율(USD 1,380원, EUR 1,500원 등)은 예시값입니다.
- 독촉 메일은 초안이므로 [Your Name], [Company Name]과 거래처 담당자 이름을 바꿔서 쓰세요.

## 파일 구성
- `index.html` — 사이트 전체(이 파일 하나만 있어도 동작합니다)
- `예시_인보이스.tsv` — 연습용 예시 데이터(엑셀로 열 수 있음)
- `assets/dashboard-preview.webp` — 대시보드 화면 캡처
- `assets/demo.gif`, `assets/demo.webp` — 사용 시연 애니메이션(같은 내용, 형식만 다름)
